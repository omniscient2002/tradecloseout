## State and proof required

An issue can advance **OPEN → IMPLEMENTED → VERIFIED → ACCEPTED** only with:
1. Its entire **original** correction and acceptance requirements mapped to exact code paths, including alias routes/guest/role/permissions/races.
2. Source fix and positive, negative, edge-case, failure-injection and real-store tests wherever applicable. State any test that is not reproducible without live services as BLOCKED_EXTERNAL, without closing it.
3. Exact commit, tests, CI workflow and evidence of fail-closed behavior; zero regressions in the integrated final tree.
4. Independent reviewer decision on that ID. Only **ACCEPTED** counts toward the 49-item formal closure total.

Do **not** count commits, passing typechecks, or an older PR's candidate label as a closed finding. Keep external providers and services deferred under the user's instruction, while completing all provider-independent engineering and tests. A finding with operational requirements may remain blocked on those requirements.
